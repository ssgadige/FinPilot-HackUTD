## Target main journey

1. Log in as Maya Chen with generated application credentials; receive code in local Mailpit. Explain that identities, bank credentials and financial records are synthetic.
2. Financial institutions → Banks → Chase → enter Maya's generated Chase simulator credentials → consent/select accounts → link. Repeat her relevant card provider. Show 30-month history and overview indicators.
3. Run Financial Checkup. Show real Nemotron agent/tool events, transfer integrity check, cash timing issue, subscriptions and debt findings.
4. Confirm subscription preferences. Show an offer comparison with terms/source; disclose fixture offers. Choose a proposed change; build a car/debt plan without assuming unrealized savings.
5. Stress-test with a surprise expense; compare cash buffers. Accept chosen baseline plan through explicit confirmation.
6. Inject a demo expense. Show snapshot change, Plan Repair invoking tools and proposed before/after revision; user remains in control.
7. Ask basic chat 'Why did you propose this?' and open evidence. Chat is the interface; the agents do the workflow.

Seed alone does not guarantee these findings until calculation and agent tasks are implemented; validate and tune fixture scenario in FP-24 before rehearsal. Use actual generated amounts, not memorized invented numbers.

## Failure rehearsal

Missing NVIDIA key → AI unavailable. SMTP down → verification cannot complete. Offer fetch blocked → labeled fixture/no verified offer. Agent timeout → partial run. Disconnected account → stale findings and no access. Repeated event → one effect. Offline replay is permitted only if explicitly labeled replay; do not pass it as live inference.
