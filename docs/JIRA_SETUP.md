# Issue tracking

The active backlog is maintained in [GitHub Issues](https://github.com/ssgadige/FinPilot-HackUTD/issues) and the [FinPilot Development board](https://github.com/users/ssgadige/projects/1).

Jira is not connected. `jira-import.csv` contains a matching export for a future Jira project; importing it requires an Atlassian connection and the destination project. FP identifiers remain stable specification references even when Jira assigns different issue keys.
